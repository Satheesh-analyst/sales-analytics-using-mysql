# 📊 sales-analytics-using-mysql

A SQL project that analyzes customer purchasing behavior, sales performance, and product insights using MySQL. This project demonstrates SQL skills ranging from basic queries to advanced analytical techniques used in real-world business scenarios.

---

## 📌 Project Overview

The goal of this project is to explore a retail sales database and answer business questions using SQL. It includes database exploration, KPI calculations, trend analysis, customer segmentation, product analysis, and report generation.

---

## 🎯 Objectives

* Explore and understand the database structure.
* Analyze customer purchasing behavior.
* Calculate key business metrics (KPIs).
* Identify sales trends over time.
* Segment customers based on purchasing patterns.
* Analyze product performance.
* Generate business reports using SQL.
